## Terrain Generation
- Real world terrain is generated by dynamic natural processes that take place over thousands of years
	- Tectonic plate movements, volcanoes, wind, water, temperature, etc.
	- We don't have computational resources to accurately simulate those processes, but we can start with a process that roughly models real world terrain features
	- Then we can apply weathering after that
- To get the base terrain, we can use a random noise source like Perlin noise which has gradients between the random values and is less chaotic
- Perlin noise has a predefined and limited range, and therefore repeats
- We can combine Perlin noise with hierarchical rules like with a Directed Acyclic Graph, where each node specifies rules:
	- How to generate noise (Perlin scalar, zoom level, offsets)
	- How to combine with parent (add, subtract, multiply)
- **Applying Natural Processes**
	- Multiple iterations can be applied to the base terrain
	- This can be done in stages to give a more natural end result
	- Fault Lines can be created by identifying a fault line, then shifting terrain slightly relative to a fault line
	- Thermal erosion simulates bunching up of granular materials / substrate (like sand or snow)
		- Useful to limit this to certain heights or altitude bands for where to apply this (near beaches)
	- Hydraulic Erosion simulates the effects of moving water
	- Altitude Filtering applies different functions based on existing heights present
- **Rules System Methods**
	- Cellular Automaton
		- Take noise / random values, segment bits/space into grids, and each grid updates until stable or we hit a time limit
	- Rules Based Simulation
		- Take noise / random values, iterate a set of rules over the world, and continue until stable or a time limit is reached
## Object Placement
- Normal RNG can be used for object placement but it usually results in clumping and doesn't look natural
- Halton sequence leverages coprime numbers and can create a random-like but repeating (tiling) distribution
- ![](../Images/Pasted%20image%2020260720181734.png)
- Poisson distribution splits an area into a grade and places `n` items per cell, and you can dynamically change n based on other values
	- We can add in a 2 times radius check here to see if any other objects were placed within this objects range -- If so select a new point
- These approaches have only considered points so far, but we'll need circles / disks or other shapes for objects
- Perlin noise can also help with feature placement, and it typically avoids overlap due to the nature of gradient noise
